
# Kode UTS Machine Learning Kelompok 11

Repository ini berisi implementasi tiga task UTS Machine Learning.

## Task 1 - Regresi
Estimasi durasi pengiriman paket menggunakan prediksi P50 dan P90.

## Task 2 - Klasifikasi
Deteksi transaksi fraud.

## Task 3 - Clustering
Segmentasi pelanggan.

## Reproduksi
Kode akan disusun agar hasil dapat direproduksi melalui:

```bash
python kode/run_all.py
```

Catatan: perintah reproduksi akan dapat digunakan setelah seluruh skrip selesai dibuat.
